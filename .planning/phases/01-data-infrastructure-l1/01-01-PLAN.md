<objective>
Phase 1 schema foundation + provider seam interfaces.

Purpose: Every Phase 1 ingestion module (Plans 02-08) needs (a) tables to write to and (b) interfaces to implement. This plan ships both in one shot so Wave 2 plans can run in parallel without shared-file conflicts. Also validates the DATA-14 swap-in seam by shipping a `PolygonProvider` stub class — proves a paid feed can drop in by config without rewriting downstream code.

Output: Single Alembic migration `0002_create_phase1_tables.py` (raw SQL only, per D-01) creating 13 Phase 1 tables; `data/providers/base.py` with six sibling ABCs (OHLCV / Fundamentals / Filings / ShortInterest / Estimates / Macro); `data/providers/polygon_provider.py` stub raising `NotImplementedError` everywhere; `data/providers/__init__.py` re-exports.

**Plan-level decision (provider granularity):** Six sibling ABCs (one per data-feed type) instead of monolithic `MarketDataProvider`. Rationale: yfinance can implement OHLCV/Fundamentals/ShortInterest/Estimates but cannot implement Filings (EDGAR territory) or Macro (Federal Reserve territory). Sibling ABCs let each concrete provider implement only what it can. The existing monolithic `MarketDataProvider` ABC at `src/ls_equity_fund/data/base.py` is RETAINED for backward compatibility (Phase 0 INFRA-03 success criterion 3 imports it) — it remains the "facade" ABC; siblings are added alongside under `providers/base.py`.

**Plan-level decision (yfinance fundamentals D2 mitigation):** `fundamentals` table includes an `as_of_ingest_date` column (the date the row was fetched) on top of `period_end`. Append-only: each ingest writes a new row with today's `as_of_ingest_date` rather than overwriting. Downstream readers query `MAX(as_of_ingest_date)` per `(ticker, period_end, period_type)` to get the latest-known view. Future PIT-aware backtests (v2) read with `WHERE as_of_ingest_date <= replay_date` to honor look-ahead constraints.

from __future__ import annotations

from abc import ABC, abstractmethod
from datetime import date
from pathlib import Path
from typing import Any

import pandas as pd


class OHLCVProvider(ABC):
    """Daily OHLCV bars (DATA-03).

    Concrete: YFinanceProvider (Phase 1), PolygonProvider (DATA-14 stub).
    """

    @abstractmethod
    def get_prices(
        self, tickers: list[str], start: date, end: date
    ) -> pd.DataFrame:
        """Return OHLCV panel.
